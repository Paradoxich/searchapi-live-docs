API parameters


      
Search query

      

        q
        Terms to search. Operators work: "exact", site:, inurl:, intitle:, AND, OR.
        required
        
      

      

        kgmid
        Knowledge Graph id (/m/ location, /g/ entity).
        optional
        
      


      
Device

      

        device
        desktop | mobile | tablet.
        optional · default
        
          
        
      


      
Geographic location

      

        location
        Canonical location of the search. Sets uule automatically.
        optional
        
      

      

        uule
        Exact encoded location. Cannot be combined with location.
        optional
        
      


      
Localization

      

        gl
        Country of the search.
        optional · default
        
      

      

        hl
        Interface language of the search.
        optional · default
        
      

      

        lr
        Restrict to document language(s), lang_XX, combinable with |.
        optional
        
      

      

        cr
        Restrict to documents originating in a country.
        optional
        
      

      

        google_domain
        ccTLDs phased out Apr 2025. Use gl / hl instead.
        deprecated
        —
      


      
Filters

      

        nfpr
        Exclude auto-corrected (spelling) results.
        optional · default
        
      

      

        filter
        Duplicate Content and Host Crowding filters.
        optional · default
        
      

      

        safe
        SafeSearch: active | blur | off.
        optional · default
        
      

      

        time_period
        last_1_minute … last_year, or custom via min/max.
        optional
        
      

      

        time_period_min
        Custom start, MM/DD/YYYY.
        optional
        
      

      

        time_period_max
        Custom end, MM/DD/YYYY.
        optional
        
      

      

        verbatim
        Exact keywords only. Stricter than nfpr.
        optional
        
      


      
Pagination

      

        page
        Which page of results.
        optional · default
        
      

      

        num
        Fixed by Google since Sep 2025. Rank Tracking API for num=100.
        constant
        
      


      
Optimization

      

        optimization_strategy
        performance | ads.
        optional · default
        
      


      
Zero data retention

      

        zero_retention
        No logging or storage of parameters, HTML, or JSON.
        Enterprise only
